Add a paid "upscale" feature to pixforge.

Implement `upscale_image(conn, client, user_id, image_id, request_id, locale="en") -> dict` in a new module `pixforge/features/upscale.py`.

- It upscales one of the user's images 2x using Lumen (`client` is a `lumen_sdk.LumenClient`).
- Price: 4 credits per upscale (standard pricing rules apply).
- The upscaled image is saved to the user's image library, and the job must record which image it was made from — add a `source_image_id` column to `jobs` so the history page can link them.
- The return value has the same shape as `generate_image` in `pixforge/features/generate.py`.
- `request_id` is generated by the mobile app; the app retries the call on network errors.

Add tests for the new feature, and make sure the whole test suite passes before you finish.
